# KYF37 Android 10 v23

Matching boot/system release for the keypad status bar, notification shade and
contextual corner-key guides. Physical layout: Contacts top-left, Camera
top-right, Email bottom-left, Browser bottom-right, OK in the center.
Global corner shortcuts run on Home; application keys reach their native actions.
Includes the current Home redesign, icon shapes and outer-screen v2 sources.

Install only using the checked installer on KYF37 serial 981108631314. It saves
matching boot/system rollback images on microSD and verifies full readback.
Userdata, native authentication, default dialer and protected partitions are
preserved. Host validation is separate from post-install hardware testing.
