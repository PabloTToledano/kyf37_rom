Native-guide asset markers also exclude Calculator/infrared/FeliCa ports from duplicate shared bars. `verify-keypad-system-polish.py` gates repeatability/timestamps and XML layout structure. Changes require a matching ROM set; no isolated framework/services installation. Complete boot/system build passed (`/home/pablo/keypad-system-polish-images3.log`), followed by a successful final services/image rebuild (`/home/pablo/keypad-system-polish-staged-final.log`). Compiled APK/jar CRC, helper/routing provenance and SHA-256 report: `device-inspection/keypad-ui-validation/host-validation.json`. Additional stock ports receive the updated helper dex. The existing sensor init patch was made idempotent after repeated `input` groups blocked the image build. Scope and hardware acceptance checklist: `device-inspection/keypad-ui-validation/README.md`. No signed release was packaged or flashed; no hardware verification claimed.

Native Phone/Messages/Contacts also use the corner layout with their existing context action and Back fields retained; Camera/MENU follows the current F1 label, including Save in editors. Final app-footer/services/system-image rebuild passed in `/home/pablo/keypad-system-polish-staged-final3.log`. The final host report validates 11 compiled APK/jar artifacts.
